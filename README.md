# Expense Tracker

A responsive single-page expense tracker built with HTML, CSS, JavaScript, Bootstrap, and Chart.js.

## Features

- Monthly interactive calendar with daily balance totals
- Click any day to add, edit, or delete income and expense entries
- Day-level income, expense, and balance summary in the modal overlay
- Global totals for income, expenses, and current balance
- Filterable action log by type, category, and search text
- Monthly summary cards below the calendar
- Category-wise expense chart
- Browser Local Storage persistence
- Mobile-friendly layout

## How to run

1. Open `index.html` in a modern browser.
2. Add transactions from the calendar overlay.
3. Refresh the page to confirm data persists in Local Storage.

## Notes

- The app uses CDN-hosted Bootstrap and Chart.js, so an internet connection is needed the first time the page loads.
- All amounts are displayed in Indian Rupees (INR).
